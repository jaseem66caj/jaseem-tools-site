Jaseem Tools Privacy Policy

Jaseem Tools is a private set of command-line tools used only by its owner, Jaseem Abdul Jaleel. The app accesses the owner's own Google account data (such as Gmail and Calendar) solely for personal automation. OAuth tokens are stored locally on the owner's own computer and are never shared. No data is sold, shared with or transferred to third parties, and no data is used for advertising. Google user data is used in accordance with the Google API Services User Data Policy, including the Limited Use requirements. To ask about this policy or request deletion, contact jaseem66caj@gmail.com.
